# Contributing to AI File Sorter

- Fork the repository and submit pull requests.
- Report ordinary bugs or suggest features on the GitHub issue tracker.
- Start with an issue for language requests or translation improvements. The
  project uses a shared Qt workflow for language selection, translation catalogs,
  and fallbacks. [Open an issue](https://github.com/hyperfield/ai-file-sorter/issues)
- Report suspected security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
- Follow the existing code style and documentation format.
