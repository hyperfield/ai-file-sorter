## Summary

This change switches the default Local 3B model download to a Q4 quantization while preserving the previously downloaded Q8 model as a legacy option. The selection dialog also now derives file sizes from local files when remote size metadata is unavailable.

## Motivation

- The previous Q8 3B model is too large to reliably load on some Vulkan GPU setups.
- A Q4 3B model improves compatibility and reduces download size while keeping a lightweight local option.
- Existing users who already downloaded Q8 should not be forced to redownload a new file.
- The download UI should show meaningful file sizes even when a remote size lookup is skipped or unavailable.

## User-visible changes

- The Local 3B download now points to the Q4 model by default.
- A "Local 3B (legacy Q8)" option appears only when the old Q8 file exists locally.
- The "File size" label is populated from local files for completed downloads when remote metadata is missing.

## Implementation details

### Default Q4 download URL and legacy Q8 URL retained

The embedded `.env` now points the Local 3B download to a Q4 file while preserving a separate legacy URL for the old Q8 file.

```env
LOCAL_LLM_3B_DOWNLOAD_URL=https://huggingface.co/Mungert/Llama-3.2-3B-Instruct-GGUF/resolve/main/Llama-3.2-3B-Instruct-bf16-q4_k.gguf
LOCAL_LLM_3B_LEGACY_DOWNLOAD_URL=https://huggingface.co/bartowski/Llama-3.2-3B-Instruct-GGUF/resolve/main/Llama-3.2-3B-Instruct-Q8_0.gguf
```

### Explicit legacy choice added to the model enum

A dedicated enum value makes the legacy selection explicit instead of overloading the main Local 3B choice.

```cpp
enum class LLMChoice {
    Unset,
    Remote_OpenAI,
    Remote_Gemini,
    Local_3b,
    Local_3b_legacy, // Legacy Q8 model selection.
    Local_7b,
    Custom
};
```

### Migration logic: keep legacy Q8 if already downloaded

If a user previously selected Local 3B and the new Q4 file is missing but the legacy Q8 file exists, settings migrate to the legacy choice automatically. This prevents a forced re-download.

```cpp
if (llm_choice == LLMChoice::Local_3b
    && !file_exists_for_env_url("LOCAL_LLM_3B_DOWNLOAD_URL")
    && file_exists_for_env_url("LOCAL_LLM_3B_LEGACY_DOWNLOAD_URL")) {
    llm_choice = LLMChoice::Local_3b_legacy; // Keep using existing Q8 file.
}
```

### Legacy model selection in the dialog is conditional

The legacy radio option is only shown when the corresponding file exists locally. This avoids confusing new users who have not downloaded the Q8 model.

```cpp
const bool has_legacy_3b = legacy_local_3b_available();
local3_legacy_radio->setVisible(has_legacy_3b);
local3_legacy_desc->setVisible(has_legacy_3b);
```

### Local file size fallback for completed downloads

When remote metadata is missing, the UI now falls back to the local file size for completed downloads. This applies to the main Local LLM section and the visual LLM entries.

```cpp
long long size = downloader->get_real_content_length();
if (size <= 0 && downloader->get_local_download_status() == LLMDownloader::DownloadStatus::Complete) {
    size = local_file_size_or_zero(downloader->get_download_destination()); // Read local size.
}
```

## Rationale and trade-offs

- A separate legacy enum and UI option keeps the default path clean while preserving backwards compatibility.
- Local file size fallback avoids unnecessary network checks and removes the "File size: unknown" label for previously downloaded models.
- The legacy option is hidden unless relevant, reducing UI clutter for new installs.

## Notes for maintainers

- The legacy Q8 URL is still embedded and used only when the file exists locally.
- If the legacy option is ever removed, also remove `LOCAL_LLM_3B_LEGACY_DOWNLOAD_URL`, `Local_3b_legacy`, and the UI gate in `LLMSelectionDialog`.
