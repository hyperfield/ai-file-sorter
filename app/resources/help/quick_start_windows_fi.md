# Windows-huomiot

**File Explorer** -paneeli voi nayttaa **Network Locations** -osion, jossa on liitetyt asemat, tallennetut verkkopikakuvakkeet ja viimeksi kaytetyt UNC-jaot.

Valinnainen Windows Explorer Extension antaa kaynnistaa AI File Sorterin File Explorerin oikean painikkeen valikosta. Kayta **Extensions -> Install Windows Explorer Extension...**, jos laajennusta ei ole viela asennettu.

Asennuksen jalkeen File Explorer nayttaa **AI File Sorter** -alivalikon, jossa on toimintoja kuten **Categorize**, **Rename** ja **Categorize and Rename**. AI File Sorterissa voit avata laajennuksen asetukset tai aktiviteetti-ikkunan kohdasta **Extensions -> Windows Explorer Extension**.

Jos et ole viela valinnut tai ladannut LLM:aa, avaa ensin AI File Sorter ja viimeistele mallin asetukset ennen laajennuksen kayttoa.
