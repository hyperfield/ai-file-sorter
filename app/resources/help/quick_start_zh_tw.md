# 快速入門指南

AI File Sorter 會在您檢視並核准後，協助整理檔案。

AI 負責分析，並建議分類、子分類與檔名。它不會直接動到您的檔案。只有在您確認檢視結果後，應用程式才會執行搬移或重新命名。

## 1. 選擇資料夾

使用 [瀏覽] 按鈕挑選要整理的資料夾。

常見範例：

- `Downloads`（下載）
- 桌面整理用資料夾
- 外接磁碟中的資料夾
- 專案封存資料夾

## 2. 選擇要執行的動作

使用主要選項決定應用程式要：

- 將檔案分類到資料夾
- 分析圖片
- 分析文件
- 為支援的檔案提供重新命名建議

若只需要重新命名建議，請啟用對應的「僅重新命名」模式。

## 3. 選擇分類風格

選擇最符合目標的風格：

- **預設** 適用於一般用途
- **更精細分類** 適用於需要更細緻分組的情況
- **更一致分類** 適用於希望相似檔案維持統一標籤的情況

也可以啟用分類白名單，將分類名稱限制在較小的範圍內。

## 4. 開始分析

按一下 [分析並分類檔案] 按鈕。

應用程式會掃描選定的資料夾，蒐集所需資訊，並準備檢視清單。

## 5. 套用前先檢視

檢視對話框可供檢查：

- 建議的分類
- 選擇性的子分類
- 支援檔案的重新命名建議
- 最終目的地路徑

確認前，可以調整或拒絕建議。

## 6. 套用變更

確認後，應用程式會建立所需的資料夾，並執行搬移或重新命名。

## 7. 復原上次的執行

若套用變更後想要還原，請從選單使用 [復原上次的執行]。

復原功能適用於最近一次確認的整理作業，會利用應用程式記錄的執行歷程，將檔案搬回原位，並在可能的情況下還原重新命名。

建議在同一資料夾進行下一次大規模整理前，先使用復原功能。

## 8. 從檢視結果中學習

在檢視對話框中核准分類時，應用程式可以記住這些本機決策，作為日後執行的參考提示。這不會訓練或修改 AI 模型。

學習到的範例儲存在獨立的本機資料庫中，因此清除一般分類快取並不會移除這些資料。如需移除本機學習資料，請使用 [設定] -> [重設學習行為]。

## 其他須知

- 應用程式使用本機快取，避免重複處理相同檔案，並提升一致性。
- 應用程式不會在未顯示檢視步驟的情況下自動套用變更。
- 圖片與文件選項可分別展開，以便進行更精細的控制。

## 遇到問題時

請先確認以下事項：

- 選取的資料夾是否正確
- 相關分析選項是否已啟用
- 「僅重新命名」模式是否以非預期的方式限制了結果
- 分類白名單是否過度縮小了建議範圍

如需進一步排除問題，請開啟 [說明] -> [常見問題]。
