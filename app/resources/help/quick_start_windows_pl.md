# Uwagi dotyczące Windows

Panel **Eksplorator plików** może pokazywać sekcję **Lokalizacje sieciowe** z dyskami mapowanymi, zapisanymi skrótami sieciowymi oraz ostatnio używanymi udostępnieniami UNC.

Opcjonalne rozszerzenie Windows Explorer Extension pozwala uruchomić AI File Sorter z menu kontekstowego (prawy przycisk myszy) w File Explorer. Użyj **Rozszerzenia -> Zainstaluj rozszerzenie Eksploratora Windows...** aby je uzyskać, jeśli nie jest jeszcze zainstalowane.

Po instalacji File Explorer pokazuje podmenu **AI File Sorter** z opcjami **Uporządkuj w istniejących folderach...**, **Uporządkuj w folderach kategorii...**, **Zmień nazwy plików według zawartości** oraz **Ustawienia...**. Sortowanie otwiera okno dialogowe wyboru miejsca docelowego przed analizą. W AI File Sorter użyj **Rozszerzenia -> Rozszerzenie Eksploratora Windows** aby otworzyć okno Ustawień lub Zadań rozszerzenia.

Jeśli nie wybrałeś lub nie pobrałeś jeszcze LLM, najpierw otwórz AI File Sorter i dokończ konfigurację modelu przed użyciem rozszerzenia.
