# Windows-Hinweise

Der **File Explorer**-Bereich kann einen Abschnitt **Network Locations** mit zugeordneten Laufwerken, gespeicherten Netzwerkverknuepfungen und zuletzt verwendeten UNC-Freigaben anzeigen.

Die optionale Windows Explorer Extension ermoeglicht es, AI File Sorter ueber das Rechtsklickmenu des File Explorers zu starten. Verwenden Sie **Extensions -> Install Windows Explorer Extension...**, um sie zu erhalten, wenn sie noch nicht installiert ist.

Nach der Installation zeigt File Explorer ein Untermenue **AI File Sorter** mit Aktionen wie **Categorize**, **Rename** und **Categorize and Rename**. In AI File Sorter verwenden Sie **Extensions -> Windows Explorer Extension**, um die Erweiterungseinstellungen oder das Aktivitaetsfenster zu oeffnen.

Wenn Sie noch kein LLM ausgewaehlt oder heruntergeladen haben, oeffnen Sie zuerst AI File Sorter und schliessen Sie die Modelleinrichtung ab, bevor Sie die Erweiterung verwenden.
