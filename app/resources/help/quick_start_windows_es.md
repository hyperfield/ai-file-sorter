# Notas de Windows

El panel **File Explorer** puede mostrar una seccion **Network Locations** con unidades asignadas, accesos directos de red guardados y recursos UNC usados recientemente.

La extension opcional Windows Explorer Extension le permite iniciar AI File Sorter desde el menu contextual de File Explorer. Use **Extensions -> Install Windows Explorer Extension...** para obtenerla si todavia no esta instalada.

Despues de la instalacion, File Explorer muestra un submenu **AI File Sorter** con acciones como **Categorize**, **Rename** y **Categorize and Rename**. En AI File Sorter, use **Extensions -> Windows Explorer Extension** para abrir la configuracion de la extension o la ventana de actividad.

Si aun no ha seleccionado o descargado un LLM, abra primero AI File Sorter y complete la configuracion del modelo antes de usar la extension.
