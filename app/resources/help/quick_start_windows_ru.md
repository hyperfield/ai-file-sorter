# Заметки для Windows

На панели **Проводник** может отображаться раздел **Сетевые расположения** с подключёнными сетевыми дисками, сохранёнными сетевыми ярлыками и недавно использованными UNC-ресурсами.

Необязательное расширение для Проводника Windows позволяет запускать AI File Sorter из контекстного меню Проводника. Если оно ещё не установлено, выберите **Расширения -> Установить расширение для Проводника Windows...**.

После установки в Проводнике появится подменю **AI File Sorter** с командами вроде **Categorize**, **Rename** и **Categorize and Rename**. В самом AI File Sorter откройте **Расширения -> Расширение для Проводника Windows**, чтобы перейти к настройкам расширения или окну активности.

Если вы ещё не выбрали или не скачали LLM, сначала откройте AI File Sorter и завершите настройку модели, а затем пользуйтесь расширением.
