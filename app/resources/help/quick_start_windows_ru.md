# Примечания для Windows

Панель **Проводника** может показывать раздел **Сетевые расположения** с сопоставленными дисками, сохранёнными сетевыми ярлыками и недавно использованными общими ресурсами UNC.

Опциональное расширение Проводника Windows позволяет запускать AI File Sorter из контекстного меню Проводника. Используйте **Расширения -> Установить расширение Проводника Windows...** чтобы получить его, если оно ещё не установлено.

После установки Проводник показывает подпункт меню **AI File Sorter** с **Распределить по существующим папкам...**, **Распределить по папкам категорий...**, **Переименовать файлы по содержимому**, и **Настройки...**. Сортировка открывает диалог назначения перед анализом. В AI File Sorter используйте **Расширения -> Расширение Проводника Windows**, чтобы открыть окно **Настройки...** или окно задач расширения.

Если вы ещё не выбрали или не загрузили LLM, сначала откройте AI File Sorter и завершите настройку модели перед использованием расширения.
