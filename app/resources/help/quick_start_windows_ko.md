# Windows 참고 사항

**File Explorer** 패널은 매핑된 드라이브, 저장된 네트워크 바로 가기, 최근 사용한 UNC 공유가 포함된 **Network Locations** 섹션을 표시할 수 있습니다.

선택 사항인 Windows Explorer Extension을 사용하면 File Explorer의 오른쪽 클릭 메뉴에서 AI File Sorter를 시작할 수 있습니다. 아직 설치되어 있지 않다면 **Extensions -> Install Windows Explorer Extension...**을 사용해 설치하세요.

설치 후 File Explorer에는 **Categorize**, **Rename**, **Categorize and Rename** 같은 작업이 있는 **AI File Sorter** 하위 메뉴가 표시됩니다. AI File Sorter에서는 **Extensions -> Windows Explorer Extension**을 사용해 확장 설정 또는 활동 창을 열 수 있습니다.

아직 LLM을 선택하거나 다운로드하지 않았다면, 확장을 사용하기 전에 먼저 AI File Sorter를 열고 모델 설정을 완료하세요.
