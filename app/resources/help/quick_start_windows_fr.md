# Notes Windows

Le panneau **File Explorer** peut afficher une section **Network Locations** avec les lecteurs mappes, les raccourcis reseau enregistres et les partages UNC recemment utilises.

L'extension optionnelle Windows Explorer Extension permet de lancer AI File Sorter depuis le menu contextuel de File Explorer. Utilisez **Extensions -> Install Windows Explorer Extension...** pour l'obtenir si elle n'est pas encore installee.

Apres installation, File Explorer affiche un sous-menu **AI File Sorter** avec des actions comme **Categorize**, **Rename** et **Categorize and Rename**. Dans AI File Sorter, utilisez **Extensions -> Windows Explorer Extension** pour ouvrir les parametres de l'extension ou la fenetre d'activite.

Si vous n'avez pas encore selectionne ou telecharge de LLM, ouvrez d'abord AI File Sorter et terminez la configuration du modele avant d'utiliser l'extension.
