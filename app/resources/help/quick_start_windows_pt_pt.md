# Notas do Windows

O painel do **Explorador de Ficheiros** pode mostrar uma secção **Locais de rede** com unidades mapeadas, atalhos de rede guardados e partilhas UNC recentemente utilizadas.

A extensão opcional do Explorador do Windows permite iniciar AI File Sorter a partir do menu de contexto (botão direito) do Explorador de Ficheiros. Use **Extensões -> Instalar Extensão do Explorador do Windows...** para a obter se ainda não estiver instalada.

Após a instalação, o Explorador de Ficheiros mostra um submenu **AI File Sorter** com **Organizar em pastas existentes...**, **Organizar em pastas de categorias...**, **Renomear ficheiros pelo conteúdo**, e **Definições...**. A ordenação abre uma caixa de diálogo de destino antes da análise. No AI File Sorter, use **Extensões -> Extensão do Explorador do Windows** para abrir as Definições ou a janela Tarefas da extensão.

Se ainda não selecionou ou descarregou um LLM, abra primeiro o AI File Sorter e complete a configuração do modelo antes de usar a extensão.
