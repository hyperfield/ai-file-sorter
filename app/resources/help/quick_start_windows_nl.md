# Windows-opmerkingen

Het paneel **File Explorer** kan een sectie **Network Locations** tonen met toegewezen stations, opgeslagen netwerksnelkoppelingen en recent gebruikte UNC-shares.

De optionele Windows Explorer Extension laat u AI File Sorter starten vanuit het rechtsklikmenu van File Explorer. Gebruik **Extensions -> Install Windows Explorer Extension...** om deze te verkrijgen als hij nog niet is geinstalleerd.

Na installatie toont File Explorer een submenu **AI File Sorter** met acties zoals **Categorize**, **Rename** en **Categorize and Rename**. Gebruik in AI File Sorter **Extensions -> Windows Explorer Extension** om de instellingen van de extensie of het activiteitenvenster te openen.

Als u nog geen LLM hebt gekozen of gedownload, open dan eerst AI File Sorter en voltooi de modelconfiguratie voordat u de extensie gebruikt.
