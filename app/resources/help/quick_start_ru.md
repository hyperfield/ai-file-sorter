# Руководство по быстрому запуску

AI File Sorter помогает организовать файлы с рабочим процессом «сначала проверка» и необязательным автоматическим подтверждением, которая предварительно отмечает изменения в списке проверки.

ИИ предлагает категории, целевые папки и названия. Приложение выполняет перемещения или переименования только после того, как вы подтвердите выбранные изменения в диалоге проверки.

## Первый запуск: безопасность

Если вы используете AI File Sorter впервые, начните с небольшой тестовой папки, прежде чем направлять его на большой архив или диск.

Подходящие папки для первого запуска:

- копия из 20–50 файлов из `Downloads`
- небольшая папка для очистки скриншотов или фотографий
- временная папка с несколькими PDF или документами

Это делает первый запуск простым для проверки. Ваши файлы остаются на компьютере при использовании локальных моделей, и ИИ только предлагает категории и имена. На первом запуске оставьте опции авто-подтверждения выключенными, чтобы ничего не перемещалось и не переименовывалось, пока вы не одобрите список проверки.

Опциональный онлайн-поиск мест отправляет GPS-координаты фотографий, округлённые до трёх десятичных знаков, в сервис Nominatim от OpenStreetMap, даже при использовании локальных моделей. Поставщик также может видеть ваш IP-адрес и время запроса. Файлы фотографий, имена файлов и даты съёмки не отправляются; обогащение категорий только по дате остаётся локальным.

## Настройка LLM

Откройте **Настройки -> Выбрать LLM**. Выберите модель из выпадающего списка **Локальные LLM** или провайдера в **API-подключения**.

**Qwen3.5 4B (Recommended)** — первый локальный вариант и настройка по умолчанию для новых установок. Она обеспечивает высокую точность категоризации и рекомендуется для существующих структур папок. Ваш ранее сохранённый выбор модели сохраняется. Чтобы использовать свой собственный файл GGUF, выберите **Пользовательский локальный LLM (gguf)** и нажмите **Добавить**.

Для встроенной локальной модели разверните **Загрузки**, нажмите **Скачать** и дождитесь сообщения **Model ready** перед подтверждением **ОК**. **Хранилище моделей** позволяет выбрать папку для загрузки. **Подробнее** показывает URL загрузки, локальный путь и техническую информацию.

Для локального анализа изображений выберите **Визуальная модель** в разделе **Модели для анализа изображений** и скачайте необходимые файлы. Визуальная модель выбирается отдельно от текстовой модели.

В разделе **API-подключения** можно выбрать Gemini, ChatGPT (OpenAI) или настроить совместимый с OpenAI конечный пункт, затем ввести требуемые данные подключения и имя модели. Облачные API требуют доступа в интернет и отправляют данные анализа на настроенный сервис. Пользовательские конечные пункты также могут работать локально.

Чтобы анализировать изображения через совместимый с OpenAI API, включите для этого подключения опцию **Модель с возможностью обработки изображений**, затем выберите его в **Модели для анализа изображений → Визуальная модель**. Локальная модель или загрузка проекторов не требуются. Включение поддержки vision запрашивает подтверждение, что содержимое изображений будет отправлено на настроенный сервер.

## Проверка локальной производительности (опционально)

После загрузки моделей откройте **Файл -> Проверка совместимости системы** и нажмите **Запустить тест**. Сначала закройте другие ресурсоёмкие приложения, нагружающие CPU или GPU. Проверка тестирует загруженные локальные модели, включая пользовательские GGUF-модели.

Оставьте **Бэкенд** в положении **Автоматически (использовать CPU, если GPU не доступен)** или выберите **Все доступные бэкенды**, чтобы сравнить CPU и поддерживаемые варианты GPU. Результаты сохраняются отдельно для каждой модели и бэкенда; неудача для одной комбинации не исключает работу другой.

Выберите результат и используйте кнопку **Повторить выбранные**, чтобы повторить эту комбинацию, **Повторить неудавшиеся**, чтобы повторить неудачные комбинации, или **Попробовать выбранный бэкенд**, чтобы протестировать выбранную модель с конкретным бэкендом из выпадающего списка.

Рекомендации оценивают локальную производительность. Проверка не тестирует API-службы и не оценивает точность при выборе существующих папок; она также не меняет выбранную модель автоматически.

## 1. Выберите папку

Используйте **Обзор** или панель проводника файлов, чтобы выбрать папку, которую вы хотите сортировать.

Типичные примеры:

- `Downloads`
- папка для очистки на рабочем столе
- папка на внешнем диске
- папка в сети или синхронизированная с облаком
- архив проекта

**Место назначения** контролирует, куда попасть отсортированные файлы. Оставьте включенной опцию **Использовать анализируемую папку**, чтобы сортировать внутри выбранной папки, или выключите её и укажите другую папку назначения.

## 2. Выберите, что должно делать приложение

Используйте основные опции, чтобы решить, должно ли приложение:

- распределять файлы по папкам по категориям
- анализировать изображения
- анализировать документы
- предлагать варианты переименований для поддерживаемых файлов

Если вы хотите только предложения по переименованию, включите **Предлагать переименовать файлы изображений** или **Предлагать переименовать документы**, затем включите **Переименовывать изображения без перемещения** или **Переименовывать документы без перемещения** для соответствующего типа файлов.

**Сортировка папок** перемещает папки целиком вместе с их содержимым и отключает **Сканировать подпапки**. Чтобы сканировать файлы внутри подпапок вместо этого, выключите **Сортировать папки** и включите **Сканировать подпапки**.

## 3. Выберите способ сортировки

Новые профили стартуют с **Использовать существующую структуру папок**. Ранее сохранённые
варианты режима сортировки сохраняются. Выберите **Место назначения**, содержащую
папки, которые вы хотите использовать, или выберите **Создавать папки категорий** для их генерации.

Выберите режим сортировки:

- **Создавать папки категорий** создаёт папки из предлагаемых названий категорий.
- **Использовать существующую структуру папок** выбирает папки внутри дерева вашей **Место назначения**. Включите **Предлагать новые папки при необходимости**, чтобы разрешить создание новых мест назначения, когда ни одно не подходит; оставьте выключенным, чтобы использовать только существующие папки.

Используйте **Создать структуру папок**, чтобы добавить стартовое дерево в ваше назначение. Его
**Язык папок** устанавливается в язык ваших категорий и может быть изменён
только для этой структуры. Ненглишевые имена папок переводятся с помощью выбранной
LLM. Просмотрите переведённый предварительный просмотр перед нажатием **Создать**; нумерация папок и вложенность сохраняются.

Для существующих папок мы рекомендуем **Qwen3.5 4B**. **Gemma 1.1 7B** и модели, доступные через API, также подходят. Другие локальные модели показывают предупреждение; вы можете оставить свою модель или сменить её в **Настройки -> Выбрать LLM**.

В режиме **Создавать папки категорий** выберите стиль категоризации:

- **Более подробный** для общего использования и более тонкой группировки
- **Более единообразный** если вы хотите более строгую согласованность меток для похожих файлов

Белые списки категорий ограничивают предлагаемые имена категорий и подкатегорий в режиме **Создавать папки категорий**. Они отключены и игнорируются в режиме **Использовать существующую структуру папок**, который использует вашу структуру назначения. Ваше предпочтение белого списка сохраняется при переключении режимов.

## 4. Начните анализ

Нажмите **Анализировать папку**.

Приложение сканирует выбранную папку, собирает необходимую информацию и подготавливает список для проверки.

## 5. Проверьте перед применением изменений

В диалоге проверки вы можете просмотреть:

- предлагаемые категории
- опционные подкатегории
- предложения по переименованию для поддерживаемых файлов
- итоговые пути назначения
- предпросмотры файлов, где поддерживается

Вы можете скорректировать или отклонить предложения до подтверждения любых действий.

Включите **Тестовый прогон (только просмотр, файлы не перемещаются)**, чтобы просмотреть планируемые перемещения и переименования, не применяя их.

## 6. Примените изменения

Выберите строки, которые хотите обработать, и нажмите **Применить изменения**. Приложение создаст необходимые папки и выполнит выбранные перемещения или переименования.

**Предварительный просмотр тестового запуска**: включите **Тестовый прогон (только просмотр, файлы не перемещаются)**, чтобы просмотреть планируемые перемещения и переименования без их применения.

**Автоматически выбирать предложения по переименованию** и **Автоматически выбирать предложения по сортировке** заранее выбирают подходящие строки. Тем не менее вам всё равно нужно подтвердить изменения перед их применением.

## 7. Отменить последний запуск

Если вы применили изменения и хотите их отменить, используйте **Правка -> Отменить последний запуск**.

Отмена предназначена для самого последнего подтверждённого запуска сортировки. Она использует историю запусков, записанную приложением, чтобы вернуть файлы на место и по возможности обратить поддерживаемые переименования.

Для наилучших результатов используйте Отмену перед началом другой крупной очистки в той же папке.

## 8. Обучение на ваших проверках

Когда вы подтверждаете категории в диалоге проверки, приложение может запомнить эти локальные решения и использовать их как подсказки в будущих запусках. Это не обучает и не изменяет саму модель ИИ.

Изученные примеры сохраняются в отдельной локальной базе данных, поэтому очистка обычного кеша категоризации их не удаляет. Чтобы удалить эти данные локального обучения, используйте **Настройки -> Сбросить обученное поведение**.

## Полезно знать

- Приложение использует локальный кеш, чтобы избежать повторной обработки одних и тех же файлов и повысить согласованность.
- Авто-подтверждение — опционально. Оставляйте его выключенным, пока не будете уверены в предложениях приложения.
- Опции для изображений и документов можно расширять отдельно, если вам нужен больший контроль.

## Если что-то выглядит неправильно

Сначала проверьте следующее:

- выбрана ли нужная папка
- включены ли соответствующие опции анализа
- режим только переименования не ограничивает ли результат нежелательным образом
- белый список категорий не сужает ли предложения слишком сильно

Для дополнительной отладки откройте **Справка -> Часто задаваемые вопросы**.
