# Примітки для Windows

Панель **Провідник файлів** може показувати розділ **Мережеві розташування** з підключеними мережевими дисками, збереженими мережевими ярликами та нещодавно використаними UNC-шарами.

Додаткове розширення Windows Explorer дозволяє запускати AI File Sorter з контекстного меню Провідника файлів. Використайте **Розширення -> Встановити розширення Провідника Windows...**, щоб встановити його, якщо воно ще не інстальоване.

Після встановлення Провідник файлів показує підменю **AI File Sorter** з пунктами **Розподілити до наявних тек...**, **Розподілити до тек категорій...**, **Перейменувати файли за вмістом** та **Налаштування...**. Під час сортування перед аналізом відкривається діалог вибору папки призначення. У AI File Sorter використовуйте **Розширення -> Розширення Провідника Windows**, щоб відкрити вікно налаштувань або завдань розширення.

Якщо ви ще не вибрали або не завантажили LLM, спочатку відкрийте AI File Sorter і завершіть налаштування моделі перед використанням розширення.
