# 快速入门指南

AI File Sorter 通过先审核的工作流程帮助您整理文件，并可对您选择信任的更改启用可选的自动批准。

AI 负责分析并建议类别、子类别和名称。它不会直接修改您的文件。应用会在您确认审核后的更改之后执行移动或重命名；只有在您启用相应自动批准设置时，才会自动执行符合条件的更改。

## 安全的首次运行

如果这是您第一次使用 AI File Sorter，请先从一个小型测试文件夹开始，不要一开始就选择大型档案或整个驱动器。

适合首次运行的文件夹包括：

- 从 `Downloads` 复制出的 20-50 个文件
- 一个用于清理截图或照片的小文件夹
- 一个包含少量 PDF 或文档的临时文件夹

这样首次运行更容易审核。使用本地模型时，您的文件会保留在本机，AI 只会建议类别和名称。首次运行时请关闭自动批准选项，这样在您批准审核列表之前，不会移动或重命名任何内容。

## 1. 选择一个文件夹

使用 **Browse** 或 **File Explorer** 面板选择要整理的文件夹。

常见示例：

- `Downloads`
- 桌面清理文件夹
- 外部驱动器文件夹
- 网络文件夹或云同步文件夹
- 项目档案

## 2. 选择应用应执行的操作

使用主要选项决定应用是否应：

- 将文件分类到文件夹中
- 分析图片
- 分析文档
- 为受支持的文件提供重命名建议

如果您只想要重命名建议，请启用相应的仅重命名模式。

## 3. 选择分类风格

选择最符合您目标的风格：

- **More refined** 适合一般用途和更细致的分组
- **More consistent** 适合希望相似文件之间的标签更一致

如果希望应用只使用较窄范围内的类别名称，也可以启用类别白名单。

## 4. 开始分析

单击 **Analyze and categorize files**。

应用会扫描所选文件夹，收集所需信息，并准备审核列表。

## 5. 应用更改前先审核

审核对话框可让您检查：

- 建议的类别
- 可选的子类别
- 受支持文件的重命名建议
- 最终目标路径
- 受支持文件的预览

您可以在确认任何内容之前调整或拒绝建议。

## 6. 应用更改

确认后，应用会创建所需文件夹并执行移动或重命名。如果启用了自动批准，符合条件的类别或文件名更改可以不经过审核对话框停顿而直接应用。

## 7. 撤销上次运行

如果您应用更改后想要还原它们，请使用菜单中的 **Undo last run**。

撤销功能用于最近一次已确认的整理运行。它使用应用记录的运行历史，在可能的情况下将文件移回原处并撤销受支持的重命名。

为获得最佳结果，请在同一文件夹中开始另一次大型清理之前使用撤销。

## 8. 从您的审核中学习

当您在审核对话框中批准类别时，应用可以记住这些本地决定，并在以后运行时将其作为提示。这不会训练或修改 AI 模型。

学习到的示例存储在单独的本地数据库中，因此清除普通分类缓存不会删除它们。若要移除这些本地学习数据，请使用 **Settings -> Reset learned behavior**。

## 注意事项

- 应用使用本地缓存以避免重复处理相同文件，并提高一致性。
- 自动批准是可选的。请在熟悉应用建议之前保持关闭。
- 如果需要更多控制，可以分别展开图片和文档选项。

## 如果看起来有问题

请先检查以下内容：

- 所选文件夹确实是您想要的文件夹
- 相关分析选项已启用
- 仅重命名模式没有以意外方式限制结果
- 类别白名单没有过度缩小建议范围

如需更多故障排除，请打开 **Help -> FAQ**。
