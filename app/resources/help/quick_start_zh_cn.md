# 快速入门指南

AI File Sorter 通过先审核再应用的流程帮助您整理文件。可选的自动批准功能可以在审核列表中预先勾选更改。

AI 会建议类别、目标文件夹和名称。只有在您通过审核对话框确认选中的更改后，应用才会移动或重命名文件。

## 安全的首次运行

如果这是您第一次使用 AI File Sorter，请先从一个小型测试文件夹开始，不要一开始就选择大型档案或整个驱动器。

适合首次运行的文件夹包括：

- 从 `Downloads` 复制出的 20-50 个文件
- 一个用于清理截图或照片的小文件夹
- 一个包含少量 PDF 或文档的临时文件夹

这样首次运行更容易审核。使用本地模型时，您的文件会保留在本机，AI 只会建议类别和名称。首次运行时请关闭自动批准选项，这样在您批准审核列表之前，不会移动或重命名任何内容。

## 设置 LLM

打开 **Settings -> Select LLM**。从 **Local LLMs** 下拉列表选择模型，或在 **API connections** 中选择服务提供商。

**Qwen3.5 4B (Recommended)** 是第一个本地选项，也是新配置的默认模型。它提供高精度分类，推荐用于现有文件夹结构。您之前保存的模型选择会保留。如需使用自己的 GGUF 文件，请选择 **Custom local LLM (gguf)**，然后点击 **Add**。

对于应用提供的本地模型，展开 **Downloads**，点击 **Download**，等待显示 **Model ready** 后再点击 **OK** 确认。**Model storage** 可设置下载文件夹。**See details** 可显示下载 URL、本地路径和技术信息。

如需分析图片，还要在 **Image analysis models** 中选择 **Visual model**，并下载所需的全部文件。此选择与文本模型相互独立。

在 **API connections** 中选择 Gemini、ChatGPT (OpenAI) 或自定义 OpenAI 兼容端点，然后输入所需的连接信息和模型名称。云端 API 需要联网，并会将分析输入发送到配置的服务。自定义端点也可以在本地运行。

## 检查本地性能（可选）

下载模型后，打开 **File -> System compatibility check**，点击 **Run benchmark**。请先关闭其他大量占用 CPU 或 GPU 的应用。此检查会测试已下载的本地模型，包括自定义 GGUF 模型。

将 **Backend** 保持为 **Automatic (try CPU if GPU fails)**，或选择 **All available backends** 来比较 CPU 和支持的 GPU 选项。结果会按模型和后端分别保存；某个后端失败不会排除在其他后端正常工作的组合。

选择一条结果，使用 **Retry selected** 重新测试该组合，使用 **Retry failed** 重新测试失败的组合，或使用 **Try chosen backend**，通过下拉列表中的特定后端测试所选模型。

推荐结果用于估计本地性能。此检查不测试 API 服务，也不评估选择现有文件夹的准确性，并且不会自动更改您选择的模型。

## 1. 选择一个文件夹

使用 **Browse** 或 **File Explorer** 面板选择要整理的文件夹。

常见示例：

- `Downloads`
- 桌面清理文件夹
- 外部驱动器文件夹
- 网络文件夹或云同步文件夹
- 项目档案

**Destination** 决定整理后的文件存放在哪里。保持 **Use analyzed folder** 启用可在所选文件夹内整理；关闭后可浏览并选择其他目标文件夹。

## 2. 选择应用应执行的操作

使用主要选项决定应用是否应：

- 将文件分类到文件夹中
- 分析图片
- 分析文档
- 为受支持的文件提供重命名建议

如果您只想要重命名建议，请启用相应的仅重命名模式。

## 3. 选择整理方式

选择一种整理模式：

- **Create category folders** 根据建议的类别名称创建文件夹。
- **Use existing folder structure** 从 **Destination** 下的文件夹树中选择文件夹。启用 **Suggest new folders when needed** 可在没有合适文件夹时允许建议新目标；关闭此选项则只使用现有文件夹。

对于现有文件夹，我们推荐 **Qwen3.5 4B**。**Gemma 1.1 7B** 和通过 API 使用的模型也是合适的选择。其他本地模型会显示提示；您可以继续使用当前模型，也可以在 **Settings -> Select LLM** 中更改。

在 **Create category folders** 模式下，选择分类风格：

- **More refined** 适合一般用途和更细致的分组
- **More consistent** 适合希望相似文件之间的标签更一致

如果希望应用只使用较窄范围内的类别名称，也可以启用类别白名单。

## 4. 开始分析

单击 **Analyze folder**。

应用会扫描所选文件夹，收集所需信息，并准备审核列表。

## 5. 应用更改前先审核

审核对话框可让您检查：

- 建议的类别
- 可选的子类别
- 受支持文件的重命名建议
- 最终目标路径
- 受支持文件的预览

您可以在确认任何内容之前调整或拒绝建议。

启用 **Dry run (preview only, do not move files)** 可预览计划中的移动和重命名，而不实际执行。

## 6. 应用更改

勾选要处理的行，然后点击 **Confirm and Process**。应用会创建所需文件夹，并执行选中的移动或重命名。

**Auto-approve filename changes** 和 **Auto-approve categorization** 会预先勾选符合条件的行。应用这些更改之前，仍然需要您确认。

## 7. 撤销上次运行

如果您应用更改后想要还原它们，请使用菜单中的 **Edit -> Undo last run**。

撤销功能用于最近一次已确认的整理运行。它使用应用记录的运行历史，在可能的情况下将文件移回原处并撤销受支持的重命名。

为获得最佳结果，请在同一文件夹中开始另一次大型清理之前使用撤销。

## 8. 从您的审核中学习

当您在审核对话框中批准类别时，应用可以记住这些本地决定，并在以后运行时将其作为提示。这不会训练或修改 AI 模型。

学习到的示例存储在单独的本地数据库中，因此清除普通分类缓存不会删除它们。若要移除这些本地学习数据，请使用 **Settings -> Reset learned behavior**。

## 注意事项

- 应用使用本地缓存以避免重复处理相同文件，并提高一致性。
- 自动批准是可选的。请在熟悉应用建议之前保持关闭。
- 如果需要更多控制，可以分别展开图片和文档选项。

## 如果看起来有问题

请先检查以下内容：

- 所选文件夹确实是您想要的文件夹
- 相关分析选项已启用
- 仅重命名模式没有以意外方式限制结果
- 类别白名单没有过度缩小建议范围

如需更多故障排除，请打开 **Help -> FAQ**。
