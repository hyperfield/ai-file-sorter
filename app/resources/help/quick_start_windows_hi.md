# Windows नोट्स

**File Explorer** पैनल **Network Locations** अनुभाग दिखा सकता है, जिसमें मैप की गई ड्राइव, सहेजे गए नेटवर्क शॉर्टकट और हाल में उपयोग किए गए UNC शेयर शामिल होते हैं।

वैकल्पिक Windows Explorer Extension आपको File Explorer के राइट-क्लिक मेनू से AI File Sorter शुरू करने देता है। यदि यह अभी स्थापित नहीं है, तो इसे पाने के लिए **Extensions -> Install Windows Explorer Extension...** का उपयोग करें।

स्थापना के बाद, File Explorer **AI File Sorter** उपमेनू दिखाता है जिसमें **Categorize**, **Rename** और **Categorize and Rename** जैसे कार्य होते हैं। AI File Sorter में, एक्सटेंशन सेटिंग्स या गतिविधि विंडो खोलने के लिए **Extensions -> Windows Explorer Extension** का उपयोग करें।

यदि आपने अभी तक LLM चुना या डाउनलोड नहीं किया है, तो एक्सटेंशन का उपयोग करने से पहले AI File Sorter खोलें और मॉडल सेटअप पूरा करें।
