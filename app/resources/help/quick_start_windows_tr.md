# Windows notlari

**File Explorer** bolmesi, eslenmis suruculer, kaydedilmis ag kisayollari ve son kullanilan UNC paylasimlarini iceren bir **Network Locations** bolumu gosterebilir.

Istege bagli Windows Explorer Extension, File Explorer'in sag tiklama menusunden AI File Sorter'i baslatmanizi saglar. Henuz kurulu degilse almak icin **Extensions -> Install Windows Explorer Extension...** secenegini kullanin.

Kurulumdan sonra File Explorer, **Categorize**, **Rename** ve **Categorize and Rename** gibi eylemleri iceren bir **AI File Sorter** alt menusu gosterir. AI File Sorter icinde uzanti ayarlarini veya etkinlik penceresini acmak icin **Extensions -> Windows Explorer Extension** secenegini kullanin.

Henuz bir LLM secmediyseniz veya indirmediyseniz, uzantiyi kullanmadan once AI File Sorter'i acin ve model kurulumunu tamamlayin.
