# Windows-notater

**File Explorer**-panelet kan vise en **Network Locations**-seksjon med tilordnede stasjoner, lagrede nettverkssnarveier og nylig brukte UNC-delinger.

Den valgfrie Windows Explorer Extension lar deg starte AI File Sorter fra hoyreklikkmenyen i File Explorer. Bruk **Extensions -> Install Windows Explorer Extension...** for a hente den hvis den ikke er installert enna.

Etter installasjon viser File Explorer en **AI File Sorter**-undermeny med handlinger som **Categorize**, **Rename** og **Categorize and Rename**. I AI File Sorter bruker du **Extensions -> Windows Explorer Extension** for a apne utvidelsens innstillinger eller aktivitetsvindu.

Hvis du ikke har valgt eller lastet ned en LLM enna, apne AI File Sorter forst og fullfor modelloppsettet for du bruker utvidelsen.
