# Windows-anteckningar

Panelen **File Explorer** kan visa en **Network Locations**-sektion med mappade enheter, sparade natverksgenvagar och nyligen anvanda UNC-resurser.

Den valfria Windows Explorer Extension later dig starta AI File Sorter fran File Explorers hogerklikksmeny. Anvand **Extensions -> Install Windows Explorer Extension...** for att hamta den om den inte redan ar installerad.

Efter installationen visar File Explorer en **AI File Sorter**-undermeny med atgarder som **Categorize**, **Rename** och **Categorize and Rename**. I AI File Sorter anvander du **Extensions -> Windows Explorer Extension** for att oppna tillaggets installningar eller aktivitetsfonster.

Om du annu inte har valt eller laddat ner en LLM, oppna AI File Sorter forst och slutfor modellinstallningen innan du anvander tillagget.
