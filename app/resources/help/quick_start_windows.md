# Windows Notes

The **File Explorer** pane can show a **Network Locations** section with mapped drives, saved network shortcuts, and recently used UNC shares.

The optional Windows Explorer Extension lets you start AI File Sorter from File Explorer's right-click menu. Use **Extensions -> Install Windows Explorer Extension...** to get it if it is not installed yet.

After installation, File Explorer shows an **AI File Sorter** submenu with actions such as **Categorize**, **Rename**, and **Categorize and Rename**. In AI File Sorter, use **Extensions -> Windows Explorer Extension** to open the extension settings or activity window.

If you have not selected or downloaded an LLM yet, open AI File Sorter first and complete the model setup before using the extension.
