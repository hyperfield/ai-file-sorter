# Windows 说明

**File Explorer** 面板可以显示 **Network Locations** 区域，其中包含映射驱动器、已保存的网络快捷方式以及最近使用的 UNC 共享。

可选的 Windows Explorer Extension 可让您从 File Explorer 的右键菜单启动 AI File Sorter。如果尚未安装，请使用 **Extensions -> Install Windows Explorer Extension...** 获取它。

安装后，File Explorer 会显示一个 **AI File Sorter** 子菜单，其中包含 **Categorize**、**Rename** 和 **Categorize and Rename** 等操作。在 AI File Sorter 中，可使用 **Extensions -> Windows Explorer Extension** 打开扩展设置或活动窗口。

如果您尚未选择或下载 LLM，请先打开 AI File Sorter 并完成模型设置，然后再使用扩展。
