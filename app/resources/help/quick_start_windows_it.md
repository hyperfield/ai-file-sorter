# Note Windows

Il riquadro **File Explorer** puo mostrare una sezione **Network Locations** con unita mappate, collegamenti di rete salvati e condivisioni UNC usate di recente.

L'estensione opzionale Windows Explorer Extension consente di avviare AI File Sorter dal menu di scelta rapida di File Explorer. Usa **Extensions -> Install Windows Explorer Extension...** per ottenerla se non e ancora installata.

Dopo l'installazione, File Explorer mostra un sottomenu **AI File Sorter** con azioni come **Categorize**, **Rename** e **Categorize and Rename**. In AI File Sorter, usa **Extensions -> Windows Explorer Extension** per aprire le impostazioni dell'estensione o la finestra attivita.

Se non hai ancora selezionato o scaricato un LLM, apri prima AI File Sorter e completa la configurazione del modello prima di usare l'estensione.
