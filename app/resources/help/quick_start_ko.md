# 빠른 시작 가이드

AI File Sorter는 변경 사항을 먼저 검토하는 방식으로 파일을 정리합니다. 선택 사항인 자동 승인은 검토 목록에서 변경 사항을 미리 선택할 수 있습니다.

AI는 카테고리, 대상 폴더, 이름을 제안합니다. 앱은 검토 대화상자에서 선택한 변경 사항을 확인한 후에만 파일을 이동하거나 이름을 변경합니다.

## 안전한 첫 실행

AI File Sorter를 처음 사용하는 경우 큰 보관 폴더나 드라이브를 선택하기 전에 작은 테스트 폴더로 시작하세요.

첫 실행에 적합한 폴더는 다음과 같습니다.

- `Downloads`에서 복사한 20-50개의 파일
- 작은 스크린샷 또는 사진 정리 폴더
- PDF나 문서 몇 개가 들어 있는 임시 폴더

이렇게 하면 첫 실행을 쉽게 검토할 수 있습니다. 로컬 모델을 사용할 때 파일은 컴퓨터에 그대로 남아 있으며, AI는 카테고리와 이름만 제안합니다. 첫 실행에서는 자동 승인 옵션을 꺼 두어 검토 목록을 승인하기 전에는 아무것도 이동되거나 이름이 바뀌지 않도록 하세요.

## LLM 설정

**Settings -> Select LLM**을 여세요. **Local LLMs** 드롭다운에서 모델을 선택하거나 **API connections**에서 제공업체를 선택하세요.

**Qwen3.5 4B (Recommended)**는 첫 번째 로컬 옵션이며 새 설정의 기본 모델입니다. 분류 정확도가 높으며 기존 폴더 구조에 권장됩니다. 이전에 저장한 모델 선택은 유지됩니다. 자신의 GGUF 파일을 사용하려면 **Custom local LLM (gguf)**를 선택하고 **Add**를 누르세요.

앱에서 제공하는 로컬 모델은 **Downloads**를 펼치고 **Download**를 클릭한 다음 **Model ready**가 표시될 때까지 기다린 후 **OK**로 확인하세요. **Model storage**에서 다운로드 폴더를 선택할 수 있습니다. **See details**는 다운로드 URL, 로컬 경로, 기술 정보를 보여 줍니다.

이미지 분석을 하려면 **Image analysis models**에서 **Visual model**도 선택하고 필요한 모든 파일을 다운로드하세요. 이 선택은 텍스트 모델과 별개입니다.

**API connections**에서 Gemini, ChatGPT (OpenAI), 사용자 지정 OpenAI 호환 엔드포인트 중 하나를 선택한 뒤 필요한 연결 정보와 모델 이름을 입력하세요. 클라우드 API는 인터넷 연결이 필요하며 분석 입력을 설정된 서비스로 전송합니다. 사용자 지정 엔드포인트는 로컬에서도 실행할 수 있습니다.

## 로컬 성능 확인(선택 사항)

모델을 다운로드한 후 **File -> System compatibility check**를 열고 **Run benchmark**를 클릭하세요. 먼저 CPU나 GPU를 많이 사용하는 다른 앱을 종료하세요. 이 검사는 사용자 지정 GGUF 모델을 포함하여 다운로드된 로컬 모델을 테스트합니다.

**Backend**를 **Automatic (try CPU if GPU fails)**로 두거나 **All available backends**를 선택하여 CPU와 지원되는 GPU 옵션을 비교하세요. 결과는 모델과 백엔드별로 따로 저장됩니다. 한 백엔드에서 실패해도 다른 백엔드에서 정상 작동하는 조합은 제외되지 않습니다.

결과를 선택하고 **Retry selected**로 해당 조합을 다시 테스트하거나, **Retry failed**로 실패한 조합을 다시 테스트하세요. **Try chosen backend**는 선택한 모델을 드롭다운의 특정 백엔드로 테스트합니다.

권장 사항은 로컬 성능을 추정합니다. 이 검사는 API 서비스나 기존 폴더 선택의 정확도를 테스트하지 않으며 선택한 모델을 자동으로 변경하지 않습니다.

## 1. 폴더 선택

정리할 폴더를 선택하려면 **Browse** 또는 **File Explorer** 패널을 사용하세요.

대표적인 예:

- `Downloads`
- 데스크톱 정리 폴더
- 외장 드라이브의 폴더
- 네트워크 또는 클라우드 동기화 폴더
- 프로젝트 보관 폴더

**Destination**은 정리한 파일이 저장될 위치를 정합니다. 선택한 폴더 안에서 정리하려면 **Use analyzed folder**를 켜 두세요. 다른 대상을 사용하려면 이 옵션을 끄고 대상 폴더를 선택하세요.

## 2. 앱이 수행할 작업 선택

기본 옵션을 사용해 앱이 다음 작업을 수행할지 결정하세요.

- 파일을 폴더로 분류
- 이미지 분석
- 문서 분석
- 지원되는 파일에 대한 이름 변경 제안 제공

이름 변경 제안만 원한다면 해당 이름 변경 전용 모드를 켜세요.

## 3. 정리 방식 선택

정리 모드를 선택하세요.

- **Create category folders**는 제안된 카테고리 이름으로 폴더를 만듭니다.
- **Use existing folder structure**는 **Destination**의 폴더 트리에서 폴더를 선택합니다. 적합한 폴더가 없을 때 새 대상을 허용하려면 **Suggest new folders when needed**를 켜세요. 기존 폴더만 사용하려면 꺼 두세요.

기존 폴더에는 **Qwen3.5 4B**를 권장합니다. **Gemma 1.1 7B**와 API를 통해 사용하는 모델도 적합한 옵션입니다. 다른 로컬 모델을 사용하면 안내가 표시됩니다. 현재 모델을 유지하거나 **Settings -> Select LLM**에서 변경할 수 있습니다.

**Create category folders** 모드에서는 분류 스타일을 선택하세요.

- **More refined** 일반적인 사용과 더 세밀한 그룹화에 적합
- **More consistent** 비슷한 파일 간 레이블 일관성을 더 강하게 유지하려는 경우

앱이 더 좁은 범위의 카테고리 이름 안에서만 동작하도록 하려면 카테고리 화이트리스트도 켤 수 있습니다.

## 4. 분석 시작

**Analyze folder**를 클릭하세요.

앱은 선택한 폴더를 스캔하고 필요한 정보를 수집한 뒤 검토 목록을 준비합니다.

## 5. 변경 사항 적용 전 검토

검토 대화상자에서 다음을 확인할 수 있습니다.

- 제안된 카테고리
- 선택적 하위 카테고리
- 지원되는 파일의 이름 변경 제안
- 최종 대상 경로
- 지원되는 경우 파일 미리보기

무엇이든 확인하기 전에 제안을 조정하거나 거부할 수 있습니다.

**Dry run (preview only, do not move files)**를 켜면 예정된 이동과 이름 변경을 실제로 적용하지 않고 미리 볼 수 있습니다.

## 6. 변경 사항 적용

처리할 행을 선택하고 **Confirm and Process**를 클릭하세요. 앱은 필요한 폴더를 만들고 선택한 이동 또는 이름 변경을 수행합니다.

**Auto-approve filename changes**와 **Auto-approve categorization**은 조건에 맞는 행을 미리 선택합니다. 변경 사항이 적용되기 전에 여전히 확인이 필요합니다.

## 7. 마지막 실행 취소

변경 사항을 적용한 뒤 되돌리고 싶다면 메뉴에서 **Edit -> Undo last run**을 사용하세요.

실행 취소는 가장 최근에 확인된 정리 실행을 대상으로 합니다. 앱에 기록된 실행 기록을 사용해 가능한 경우 파일을 원래 위치로 되돌리고 지원되는 이름 변경을 되돌립니다.

같은 폴더에서 또 다른 큰 정리를 시작하기 전에 실행 취소를 사용하는 것이 가장 좋습니다.

## 8. 검토 내용에서 학습

검토 대화상자에서 카테고리를 승인하면 앱은 이러한 로컬 결정을 기억하고 이후 실행에서 힌트로 사용할 수 있습니다. 이 과정은 AI 모델을 학습시키거나 변경하지 않습니다.

학습된 예시는 별도의 로컬 데이터베이스에 저장되므로 일반 분류 캐시를 지워도 삭제되지 않습니다. 이 로컬 학습 데이터를 삭제하려면 **Settings -> Reset learned behavior**를 사용하세요.

## 알아둘 점

- 앱은 같은 파일을 다시 처리하지 않고 일관성을 높이기 위해 로컬 캐시를 사용합니다.
- 자동 승인은 선택 사항입니다. 앱의 제안에 익숙해질 때까지 꺼 두세요.
- 더 많은 제어가 필요하면 이미지와 문서 옵션을 각각 펼칠 수 있습니다.

## 문제가 있어 보이는 경우

먼저 다음을 확인하세요.

- 선택한 폴더가 의도한 폴더인지
- 관련 분석 옵션이 켜져 있는지
- 이름 변경 전용 모드가 예상하지 못한 방식으로 결과를 제한하지 않는지
- 카테고리 화이트리스트가 제안을 지나치게 좁히지 않는지

추가 문제 해결은 **Help -> FAQ**를 여세요.
