# 빠른 시작 가이드

AI File Sorter는 먼저 검토하는 흐름과 사용자가 신뢰하기로 한 변경 사항에 대한 선택적 자동 승인을 통해 파일 정리를 도와줍니다.

AI는 분석을 수행하고 카테고리, 하위 카테고리, 이름을 제안합니다. AI가 파일을 직접 변경하지는 않습니다. 앱은 사용자가 검토한 변경 사항을 확인한 뒤 이동 또는 이름 변경을 수행하며, 관련 자동 승인 설정을 켠 경우에만 자동으로 적용합니다.

## 안전한 첫 실행

AI File Sorter를 처음 사용하는 경우 큰 보관 폴더나 드라이브를 선택하기 전에 작은 테스트 폴더로 시작하세요.

첫 실행에 적합한 폴더는 다음과 같습니다.

- `Downloads`에서 복사한 20-50개의 파일
- 작은 스크린샷 또는 사진 정리 폴더
- PDF나 문서 몇 개가 들어 있는 임시 폴더

이렇게 하면 첫 실행을 쉽게 검토할 수 있습니다. 로컬 모델을 사용할 때 파일은 컴퓨터에 그대로 남아 있으며, AI는 카테고리와 이름만 제안합니다. 첫 실행에서는 자동 승인 옵션을 꺼 두어 검토 목록을 승인하기 전에는 아무것도 이동되거나 이름이 바뀌지 않도록 하세요.

## 1. 폴더 선택

정리할 폴더를 선택하려면 **Browse** 또는 **File Explorer** 패널을 사용하세요.

대표적인 예:

- `Downloads`
- 데스크톱 정리 폴더
- 외장 드라이브의 폴더
- 네트워크 또는 클라우드 동기화 폴더
- 프로젝트 보관 폴더

## 2. 앱이 수행할 작업 선택

기본 옵션을 사용해 앱이 다음 작업을 수행할지 결정하세요.

- 파일을 폴더로 분류
- 이미지 분석
- 문서 분석
- 지원되는 파일에 대한 이름 변경 제안 제공

이름 변경 제안만 원한다면 해당 이름 변경 전용 모드를 켜세요.

## 3. 분류 스타일 선택

목표에 가장 잘 맞는 스타일을 선택하세요.

- **More refined** 일반적인 사용과 더 세밀한 그룹화에 적합
- **More consistent** 비슷한 파일 간 레이블 일관성을 더 강하게 유지하려는 경우

앱이 더 좁은 범위의 카테고리 이름 안에서만 동작하도록 하려면 카테고리 화이트리스트도 켤 수 있습니다.

## 4. 분석 시작

**Analyze and categorize files**를 클릭하세요.

앱은 선택한 폴더를 스캔하고 필요한 정보를 수집한 뒤 검토 목록을 준비합니다.

## 5. 변경 사항 적용 전 검토

검토 대화상자에서 다음을 확인할 수 있습니다.

- 제안된 카테고리
- 선택적 하위 카테고리
- 지원되는 파일의 이름 변경 제안
- 최종 대상 경로
- 지원되는 경우 파일 미리보기

무엇이든 확인하기 전에 제안을 조정하거나 거부할 수 있습니다.

## 6. 변경 사항 적용

확인하면 앱이 필요한 폴더를 만들고 이동 또는 이름 변경을 수행합니다. 자동 승인이 켜져 있으면 적용 가능한 카테고리 또는 파일 이름 변경이 검토 대화상자에서 멈추지 않고 적용될 수 있습니다.

## 7. 마지막 실행 취소

변경 사항을 적용한 뒤 되돌리고 싶다면 메뉴에서 **Undo last run**을 사용하세요.

실행 취소는 가장 최근에 확인된 정리 실행을 대상으로 합니다. 앱에 기록된 실행 기록을 사용해 가능한 경우 파일을 원래 위치로 되돌리고 지원되는 이름 변경을 되돌립니다.

같은 폴더에서 또 다른 큰 정리를 시작하기 전에 실행 취소를 사용하는 것이 가장 좋습니다.

## 8. 검토 내용에서 학습

검토 대화상자에서 카테고리를 승인하면 앱은 이러한 로컬 결정을 기억하고 이후 실행에서 힌트로 사용할 수 있습니다. 이 과정은 AI 모델을 학습시키거나 변경하지 않습니다.

학습된 예시는 별도의 로컬 데이터베이스에 저장되므로 일반 분류 캐시를 지워도 삭제되지 않습니다. 이 로컬 학습 데이터를 삭제하려면 **Settings -> Reset learned behavior**를 사용하세요.

## 알아둘 점

- 앱은 같은 파일을 다시 처리하지 않고 일관성을 높이기 위해 로컬 캐시를 사용합니다.
- 자동 승인은 선택 사항입니다. 앱의 제안에 익숙해질 때까지 꺼 두세요.
- 더 많은 제어가 필요하면 이미지와 문서 옵션을 각각 펼칠 수 있습니다.

## 문제가 있어 보이는 경우

먼저 다음을 확인하세요.

- 선택한 폴더가 의도한 폴더인지
- 관련 분석 옵션이 켜져 있는지
- 이름 변경 전용 모드가 예상하지 못한 방식으로 결과를 제한하지 않는지
- 카테고리 화이트리스트가 제안을 지나치게 좁히지 않는지

추가 문제 해결은 **Help -> FAQ**를 여세요.
