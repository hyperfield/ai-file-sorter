# Windows-athugasemdir

**File Explorer**-glugginn getur synt **Network Locations**-hluta med tengdum drifum, vistudum netflokkum og nylega notudum UNC-deildum.

Valfrjalsa Windows Explorer Extension leyfir ther ad raesa AI File Sorter ur haegri-smellsvalmynd File Explorer. Notadu **Extensions -> Install Windows Explorer Extension...** til ad saekja hana ef hun er ekki uppsett enn.

Eftir uppsetningu synir File Explorer **AI File Sorter**-undirvalmynd med adgerdum eins og **Categorize**, **Rename** og **Categorize and Rename**. I AI File Sorter skaltu nota **Extensions -> Windows Explorer Extension** til ad opna stillingar vidbotarinnar eda virkni-gluggann.

Ef thu hefur ekki enn valid eda sott LLM skaltu opna AI File Sorter fyrst og ljuka uppsetningu likansins adur en thu notar vidbotina.
