## 更新亮点

- 默认整理到现有文件夹结构，支持独立目标位置、可选的新文件夹建议，以及选择文件夹的原因说明。
- 改进了文件夹选择、分类、文件名建议和允许列表处理，使结果更加一致。
- 创建初始结构，并添加可选的 Johnny.Decimal 工具，用于编号文件夹、归档索引和验证报告。
- 从更完整的下载文件夹结构开始，并单独选择新文件夹名称的语言，不受分类语言限制。
- 默认使用 **Qwen3.5 4B** 进行本地文本和图片分析，模型下拉列表更加简洁并按组显示。
- 修复了自定义 API 连接被无关的互联网连通性检查阻止的问题，包括本地 LM Studio 和 Ollama 服务器。
- 通过支持视觉的 OpenAI 兼容 API 连接分析图片，包括本地服务器，无需下载第二个模型或投影器。为连接启用视觉支持时，需确认上传图片。
- 在 **排序规则...** 中分别设置图片和文档文件名的词数上限，范围为 3 至 6 个词。
- 更可靠地分析较大或格式密集的文档，并在无法分析内容时保留已完成的分类。
- 在系统兼容性检查中比较已下载的文本和图片分析模型，保存结果，并可按模型及后端单独重试。
- 将新的整理设置和目标预览与 **AI File Sorter for File Explorer 1.1.0** 配合使用。
- 存储集成（包括 OneDrive 支持）现在使用单独安装并经过验证的插件。
- 改进了取消操作、缓存复用、非英语文件名处理、审核编辑和撤销操作的可靠性。
- 改进了 GPU 兼容性和 macOS 稳定性，包括菜单图标、Metal 后端检测和图片分析基准测试。现在要求 macOS 26.0 或更高版本。
