## Основні моменти

- За замовчуванням сортування відбувається у наявну структуру тек, передбачено окреме місце призначення, необов’язкові пропозиції нових тек та пояснення вибору теки.
- Уточнено маршрутизацію тек, категоризацію, пропозиції імен файлів та обробку білого списку для більш послідовних результатів.
- За замовчуванням використовувати **Qwen3.5 4B** для локального аналізу тексту та зображень; меню вибору моделей стало простішим і згрупованим.
- Створюйте стартові структури та додайте необов’язкові інструменти Johnny.Decimal для нумерації тек, індексів архівів і звітів перевірки.
- Розпочинайте з ширшої структури Downloads і вибирайте мову назв нових тек незалежно від мови категорій.
- Аналізуйте зображення через OpenAI-сумісні API-з’єднання з підтримкою vision, включно з локальними серверами, без завантаження другого моделі або проєктора. Підтверджуйте завантаження зображень при увімкненні підтримки vision для з’єднання.
- Надійніше аналізуйте великі та щільно форматовані документи й зберігайте завершені категорії, коли аналіз вмісту недоступний.
- Встановлюйте окремі обмеження на кількість слів у іменах файлів для зображень і документів від 3 до 6 слів у **Правила сортування...**.
- Використовуйте нові налаштування сортування та попередній перегляд призначень з **AI File Sorter for File Explorer 1.1.0**.
- Інтеграції сховищ, включно з підтримкою OneDrive, тепер працюють через окремо встановлені й перевірені плагіни.
- Виправлено проблему, коли кастомні API-з’єднання, включно з локальними серверами LM Studio і Ollama, блокувалися через незалежну перевірку підключення до інтернету.
- Порівнюйте завантажені моделі для аналізу тексту та зображень у перевірці сумісності системи; результати зберігаються, а для окремих моделей і бекендів доступні повторні спроби.
- Поліпшено скасування операцій, повторне використання кешу, обробку імен файлів неанглійською мовою, редагування перегляду та надійність скасування змін.
- Додано переклади інтерфейсу європейської португальської, польської, російської та української мов, включно з довідкою та нотатками випуску.
- Покращено сумісність з GPU і стабільність на macOS, включно з іконками меню, виявленням Metal-бекенду та бенчмарком аналізу зображень. Тепер вимагається macOS 26.0 або новіша.
