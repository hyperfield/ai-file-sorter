## Novedades destacadas

- Ordenar en una estructura de carpetas existente de forma predeterminada, con un destino independiente, sugerencias opcionales de carpetas nuevas y explicaciones de los destinos elegidos.
- Mejoras en la selección de carpetas, la categorización, los nombres sugeridos y las listas permitidas para obtener resultados más coherentes.
- Usar **Qwen3.5 4B** de forma predeterminada para analizar texto e imágenes localmente, con listas de modelos más sencillas y agrupadas.
- Crear estructuras iniciales y añadir herramientas opcionales Johnny.Decimal para carpetas numeradas, índices de archivos y informes de validación.
- Comenzar con una estructura de Descargas más completa y elegir el idioma de las carpetas nuevas independientemente del idioma de las categorías.
- Analizar imágenes mediante conexiones API compatibles con OpenAI y con visión, incluidos servidores locales, sin descargar otro modelo ni proyector. Confirmar el envío de imágenes al activar la visión en una conexión.
- Analizar documentos grandes o de formato denso con mayor fiabilidad y conservar las categorías completadas cuando el análisis del contenido no esté disponible.
- Establecer límites independientes de 3 a 6 palabras para nombres de imágenes y documentos en **Reglas de clasificación...**.
- Usar los nuevos ajustes de ordenación y las vistas previas de destino con **AI File Sorter for File Explorer 1.1.0**.
- Las integraciones de almacenamiento, incluida OneDrive, ahora usan complementos verificados instalados por separado.
- Se corrigió el bloqueo de conexiones API personalizadas, incluidos servidores locales LM Studio y Ollama, por una comprobación de Internet no relacionada.
- Comparar modelos descargados de texto e imágenes en la comprobación de compatibilidad del sistema, con resultados guardados y reintentos por modelo y motor.
- Mejoras en la cancelación, reutilización de caché, nombres de archivos no ingleses, edición durante la revisión y fiabilidad al deshacer.
- Añadidas traducciones de la interfaz al portugués europeo, polaco, ruso y ucraniano, incluidas la ayuda y las notas de versión.
- Mayor compatibilidad con GPU y estabilidad en macOS, incluidos iconos de menú, detección de Metal y pruebas de análisis de imágenes. Ahora se requiere macOS 26.0 o posterior.
