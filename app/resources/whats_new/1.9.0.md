## Highlights

- Added smart branching category whitelists, including category-specific subcategory rules and safer prompt reduction for large whitelists.
- Improved the whitelist editor so top-level categories, global subcategories, and category-specific subcategories are easier to manage.
- Added file previews to the Categorization Review dialog.
- Added structured project-folder protection for recursive scans, covering common game, Git, source-code, and creative project roots.
- Added optional Windows Explorer Extension support for context-menu categorization and rename workflows.
- Added headless review gating so Explorer-triggered jobs can prepare review plans without moving or renaming files until approved.
- Added custom visual model entries and configurable model storage for local and visual model downloads.
- Improved accessibility, local backend/runtime handling, and source-build/release packaging flows.
