## Highlights

- Sort into an existing folder structure or generated category folders. Choose a separate destination and review the target folder and routing explanation before applying changes.
- Create starter folder structures and add optional Johnny.Decimal support for numbered folders, archive indexes, and validation reports.
- Open **Sorting rules...** to set separate image and document filename word limits, from 3 to 6 words, defaulting to 3.
- Try **Qwen3.5 4B** for local text and image analysis. Gemma 3 4B IT remains the default.
- Use the new sorting settings and destination previews with **AI File Sorter for File Explorer 1.1.0**.
- Improved analysis reliability, cancellation, GPU compatibility, review editing, and undo behavior.
