## Основные изменения

- Исправлены упакованные сборки среды выполнения local-LLM для Windows: упакованные библиотеки GGML теперь запускаются на обычных x64 CPU с поддержкой SSE4.2 вместо требования AVX2.
- Исправлена подготовка встроенного CA bundle для упакованных сборок и сборок Microsoft Store - пакет сертификатов теперь записывается в доступный для записи каталог данных приложения (app data) вместо каталога установки, доступного только для чтения.
