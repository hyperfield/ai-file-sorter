## 주요 변경 사항

- 기본적으로 기존 폴더 구조에 정렬하며, 별도 대상과 선택적인 새 폴더 제안, 폴더 선택 이유를 제공합니다.
- 더 일관된 결과를 위해 폴더 선택, 카테고리 분류, 파일 이름 제안 및 허용 목록 처리를 개선했습니다.
- 시작 구조를 만들고 번호가 있는 폴더, 보관 인덱스, 검증 보고서를 위한 선택적 Johnny.Decimal 도구를 추가할 수 있습니다.
- 더 폭넓은 다운로드 폴더 구조로 시작하고 새 폴더 이름의 언어를 카테고리 언어와 별도로 선택할 수 있습니다.
- 더 단순한 그룹별 모델 목록과 함께 로컬 텍스트 및 이미지 분석에 기본으로 **Qwen3.5 4B**를 사용합니다.
- 로컬 LM Studio 및 Ollama 서버를 포함한 사용자 지정 API 연결이 관련 없는 인터넷 확인 때문에 차단되던 문제를 해결했습니다.
- 두 번째 모델이나 프로젝터를 다운로드하지 않고 로컬 서버를 포함한 이미지 지원 OpenAI 호환 API 연결로 이미지를 분석할 수 있습니다. 연결의 이미지 지원을 켤 때 이미지 전송을 확인합니다.
- **정렬 규칙...**에서 이미지와 문서 파일 이름의 단어 제한을 각각 3~6개로 설정할 수 있습니다.
- 크거나 복잡하게 서식이 지정된 문서를 더 안정적으로 분석하고, 내용 분석을 사용할 수 없을 때 완료된 카테고리를 유지합니다.
- 시스템 호환성 검사에서 다운로드한 텍스트 및 이미지 모델을 비교하고 결과를 저장하며 모델과 백엔드별로 다시 시도할 수 있습니다.
- 새 정렬 설정과 대상 미리보기를 **AI File Sorter for File Explorer 1.1.0**과 함께 사용할 수 있습니다.
- OneDrive를 포함한 저장소 연동은 이제 별도로 설치한 검증된 플러그인을 사용합니다.
- 취소, 캐시 재사용, 비영어 파일 이름, 검토 중 편집 및 실행 취소의 안정성을 개선했습니다.
- 메뉴 아이콘, Metal 백엔드 감지, 이미지 분석 벤치마크를 포함해 GPU 호환성과 macOS 안정성을 개선했습니다. 이제 macOS 26.0 이상이 필요합니다.
