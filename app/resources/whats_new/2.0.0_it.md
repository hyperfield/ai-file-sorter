## Novità principali

- Ordinare per impostazione iniziale in una struttura di cartelle esistente, con destinazione separata, suggerimenti facoltativi di nuove cartelle e spiegazioni delle scelte.
- Migliorati l'assegnazione alle cartelle, la categorizzazione, i nomi proposti e le liste consentite per risultati più coerenti.
- Usare **Qwen3.5 4B** come modello iniziale per l'analisi locale di testo e immagini, con elenchi di modelli più semplici e raggruppati.
- Creare strutture iniziali e aggiungere strumenti Johnny.Decimal facoltativi per cartelle numerate, indici di archivi e rapporti di verifica.
- Iniziare con una struttura Download più completa e scegliere la lingua delle nuove cartelle indipendentemente dalla lingua delle categorie.
- Analizzare immagini tramite API compatibili con OpenAI e dotate di visione, inclusi server locali, senza scaricare un secondo modello o proiettore. Confermare l'invio delle immagini quando si attiva la visione per una connessione.
- Analizzare più affidabilmente documenti grandi o con formattazione densa e conservare le categorie completate quando l'analisi del contenuto non è disponibile.
- Impostare limiti separati da 3 a 6 parole per i nomi di immagini e documenti in **Regole di ordinamento...**.
- Usare le nuove impostazioni di ordinamento e le anteprime delle destinazioni con **AI File Sorter for File Explorer 1.1.0**.
- Le integrazioni di archiviazione, incluso OneDrive, ora usano plugin verificati installati separatamente.
- Corretto il blocco delle connessioni API personalizzate, inclusi server locali LM Studio e Ollama, causato da un controllo Internet non pertinente.
- Confrontare modelli scaricati per testo e immagini nel controllo di compatibilità del sistema, con risultati salvati e nuovi tentativi per singoli modelli e motori.
- Migliorati annullamento, riutilizzo della cache, nomi di file non inglesi, modifiche durante la revisione e affidabilità del ripristino.
- Aggiunte traduzioni dell'interfaccia in portoghese europeo, polacco, russo e ucraino, inclusi guida e note di versione.
- Migliorate compatibilità GPU e stabilità di macOS, incluse icone dei menu, rilevamento del motore Metal e benchmark delle immagini. Ora è richiesto macOS 26.0 o successivo.
