## Основные изменения

- По умолчанию — распределение по существующей структуре папок с отдельным местом назначения, опциональными предложениями новых папок и объяснениями выбора папок.
- Улучшена маршрутизация папок, категоризация, предложения имён файлов и обработка белых списков для более последовательных результатов.
- По умолчанию для локального анализа текста и изображений используется **Qwen3.5 4B**, с упрощёнными сгруппированными выпадающими списками моделей.
- Создание стартовых структур и добавление опциональных инструментов Johnny.Decimal для пронумерованных папок, индексов архива и отчётов валидации.
- Начальная организация «Загрузки» стала шире; язык новых имён папок можно выбирать независимо от языка категорий.
- Анализ изображений через совместимые с OpenAI API подключения с поддержкой vision, включая локальные серверы, без загрузки второй модели или проектора. Подтверждайте загрузку изображений при включении поддержки vision для подключения.
- Надёжный анализ больших и плотно форматированных документов, сохранение уже завершённых категорий при отсутствии возможности анализа содержимого.
- Установлены отдельные лимиты слов в именах файлов для изображений и документов — от 3 до 6 слов — в **Правила сортировки...**.
- Используйте новые настройки сортировки и предварительный просмотр мест назначения с **AI File Sorter for File Explorer 1.1.0**.
- Интеграции хранилищ, включая поддержку OneDrive, теперь используют отдельно устанавливаемые, проверенные плагины.
- Исправлена проблема, из‑за которой нестандартные API‑подключения, включая локальные серверы LM Studio и Ollama, блокировались несвязанной проверкой интернет‑соединения.
- Сравнение загруженных моделей для анализа текста и изображений в проверке совместимости системы, с сохранением результатов и возможностью повторной проверки для отдельных моделей и бэкендов.
- Улучшены отмена операций, повторное использование кэша, обработка имён файлов на неанглийских языках, редактирование в обзоре и надёжность отмены изменений.
- Добавлены переводы интерфейса на португальский (Португалия), польский, русский и украинский, включая Справку и примечания к выпуску.
- Улучшена совместимость с GPU и стабильность на macOS, включая значки в меню, определение бэкенда Metal и бенчмарк анализа изображений. Теперь требуется macOS 26.0 или новее.
