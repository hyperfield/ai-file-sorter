## Novedades principales

- Se agregaron listas blancas de categorias con ramificacion inteligente, incluidas reglas de subcategorias por categoria y reduccion mas segura de prompts para listas blancas grandes.
- Se mejoro el editor de listas blancas para que las categorias principales, las subcategorias globales y las subcategorias especificas por categoria sean mas faciles de administrar.
- Se agregaron vistas previas de archivos al dialogo de revision de categorizacion.
- Se agrego proteccion estructurada de carpetas de proyecto para analisis recursivos, cubriendo raices comunes de proyectos de juegos, Git, codigo fuente y proyectos creativos.
- Se agrego compatibilidad opcional con Windows Explorer Extension para flujos de categorizacion y cambio de nombre desde el menu contextual.
- Se agrego control de revision en modo headless para que los trabajos iniciados desde Explorer puedan preparar planes de revision sin mover ni renombrar archivos antes de la aprobacion.
- Se agregaron entradas de modelos visuales personalizados y almacenamiento de modelos configurable para descargas de modelos locales y visuales.
- Se mejoraron la accesibilidad, el manejo del backend/runtime local y los flujos de compilacion desde codigo fuente y empaquetado de versiones.
